# Isolation-156
*(Work in Progress)*
> A 2D narrative dystopian ruler survival simulator inspired by classic mechanics, set within a multi-layered brutalist gigastructure.

---

## 🚀 Overview
**Isolation-156** is set 156 years after the catastrophic *Новый Мир* anomaly. Players take on the role of a ruler deep inside a multi-layered brutalist gigastructure, making high-stakes, card-swiping decisions that balance multi-scale resources to keep the fragile society from collapsing.

## ✨ Key Features
- **Dystopian Narrative:** Deep, atmospheric lore exploring existential themes and life inside an isolated mega-structure.
- **Card-Swiping Decisions:** Swipe-based mechanical choices where every option triggers cascading consequences for different factions and resource pools.
- **Multi-Scale Resource Management:** Carefully balance vital metrics to survive the post-anomaly cycle.
- **Localization Support:** Built with multi-language support (Russian and English).

## 🛠️ Tech Stack & Architecture
- **Language:** Python 3.x
- **Engine / Library:** `pygame-ce`
- **Design Pattern:** Modular state handling, clean separation of UI rendering and logic.

## ⚙️ How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/Alourness/Isolation-156.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Isolation-156
   ```
3. Install dependencies:
   ```bash
   pip install pygame-ce
   ```
4. Run the game:
   ```bash
   python main.py
   ```
